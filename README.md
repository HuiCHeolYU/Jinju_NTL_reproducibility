# Jinju NTL reproducibility package

Common-pixel land-cover reanalysis, 11 November 2026.

[Download the reproducibility ZIP](Jinju_NTL_reproducibility_package.zip)

- ZIP size: 5,147,516 bytes
- ZIP SHA-256: `f5ea1c9c36971377e85f7ab6e07146d41e923fd8d86e8c55a24b0b25fc728ddc`
- Files in ZIP: 84

The adopted 2012/2024 TIFFs were reaggregated on identical valid pixels within the same city boundary. All 2,422 original regression members remain. Tables, spatial-lag models, road sensitivity and case figures were updated together. NTL classifications and population results are retained.

The ZIP includes current derived inputs, coordinates, boundary, spatial weights, model-estimation code, case clips and checksums. README.txt contains execution commands and result mappings.

The two large TIFFs are identified by SHA-256 and may be requested from the corresponding author, subject to source-provider conditions. Monthly NTL observations and SGIS allocation records are not included. Official NTL download routes and upstream scripts are retained. Derived-input model reproduction and full pixel reaggregation are described separately.
